隐私政策

严格履行零日志安全准则，保障企业通信纯粹无痕。

1. 严苛的“零活动日志”守则 (Zero Activity Logs Policy)

万达云在此郑重明确：本平台全线专线网关与机房交换系统均严格运行于 RAM 内存架构之中，彻底不记录、不留存任何用户的具体网络活动数据。

本平台系统在底层逻辑上完全禁用了对以下任何信息的采集与存储机制：

  • 用户通过专线访问的任何具体网站域名、接口 URL、页面路径及请求元数据；
  • 用户传输的实际数据包正文内容、上传与下载数据流；
  • 用户的真实发起 IP 与目标服务 IP 地址记录；
  • DNS 查询解析历史（所有 DNS 查询仅在无盘加密内存中即时处理，即查即焚）。

2. 最小化账户管理数据

为确保席位订购与技术交付，我们仅保留极简基础数据：

  • 注册所必需的电子邮箱（作为身份识别凭据）；
  • 高强度加盐散列加密的密码串（系统无法反解）；
  • 仅用于套餐限额结算的周期吞吐量统计（不包含任何行为时间及流向特征）。

3. 工业级端到端加密传输

万达云在物理层专线上标配 AEAD（ChaCha20-Poly1305 / AES-256-GCM）前向安全加密机制。彻底杜绝任何中间人嗅探、流量劫持与协议指纹识别行为。

4. 隐私安全咨询

如对本隐私政策有任何技术细节疑问，可随时通过工单或邮件向万达云安全架构团队咨询。
